# Cozy Knife Kitchen

You are a senior game UI/UX designer and visual designer creating the interface and visual experience for a premium cozy arcade game called:

KNIFECRAFT

Do NOT build the full gameplay mechanics yet.

Your job in this task is to create an exceptional, production-quality UI/UX prototype and visual design system for KnifeCraft.

The prototype should demonstrate the complete player-facing interface, navigation, screens, transitions, progression UI, kitchen environment UI, recipe selection, knife shop, cutting-board shop, profile/progression, and gameplay HUD.

The actual slicing physics/gameplay can be represented with polished visual placeholders.

==================================================

GAME IDENTITY

==================================================

KnifeCraft is a cozy food-preparation game.

The player works as a preparation chef in a beautiful neighborhood café.

The core gameplay is extremely simple:

Pick an ingredient.

Swipe across it.

Slice it.

Prepare the required cuts.

Plate the ingredients.

Complete the order.

The game is designed to feel:

• relaxing

• satisfying

• tactile

• warm

• cozy

• premium

• nostalgic

• handcrafted

• peaceful

The player should feel like they are spending time in their own favorite café kitchen.

This is NOT a stressful time-management game.

Avoid:

• timers dominating the screen

• aggressive colors

• casino-like reward UI

• excessive popups

• cluttered HUD

• energy systems

• aggressive monetization UI

• flashing buttons

• unnecessary notifications

The emotional fantasy is:

"I want to spend a few minutes in this kitchen."

==================================================

PLATFORM

==================================================

Design primarily for:

YouTube Playables.

Primary orientation:

PORTRAIT.

Design target:

540 × 960 logical canvas.

Important:

Do not create desktop-style navigation bars.

Do not use tiny controls.

==================================================

CORE UI PRINCIPLE

==================================================

The cutting board is the hero.

The UI should NEVER compete with the ingredient.

During actual cutting:

approximately 80% of the screen should be the cutting surface.

The remaining area can contain:

• minimal order information

• pause

• subtle progress

The player should never feel like they are interacting with an application.

They should feel like they are interacting with a kitchen.
