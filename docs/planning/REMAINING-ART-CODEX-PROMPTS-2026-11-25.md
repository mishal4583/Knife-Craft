## Rules for every sheet

- **Fully transparent background** (real alpha: no checkerboard, no white, no grey, no shadow plate).
- One picture per grid cell, in the order listed, centred, filling about 85 % of the cell, never touching the cell edge, with empty space between pictures.
- **No text, no numbers, no letters, no logos, no watermark, no grid lines, no cell numbers.** Signs, hats and aprons carry no writing.
- Keep the sheet size and the cell size exactly (the cutter reads the sheet by cells).
- Same light on every picture (from the upper left), the same thin darker-brown outline, the same glossy finish across the whole sheet.
- Every picture must read when shown small (64 to 96 px): a bold simple silhouette first, detail second.
- Show exactly what is described; do not invent another object.

## The shared style (repeated inside each prompt so each can be pasted alone)

> Warm, glossy, hand-painted cartoon mobile-game art in the style of the existing KnifeCraft painted people: soft rounded shapes, a thin darker-brown outline, soft highlights from the upper left, a gentle shadow shape under each figure, rich honey-gold, copper, cream, warm brown and leaf-green colours, polished and cheerful, never photographic, never flat vector, never pixel art.
